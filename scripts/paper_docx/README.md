# Word copies of the paper drafts for reviewers

The papers are written as Claude Docs. For a reviewer copy:

1. Export each doc as .docx.
2. Unzip it and run `clean_for_colleague.py` (drops the internal "Note for Tim" section and sets the byline).
3. Run `format_for_a4.py` (A4 page, readable table column widths, Paper 2's duplicated figure title removed).
4. Zip it again.

The scripts change formatting only; the text is the doc's.
